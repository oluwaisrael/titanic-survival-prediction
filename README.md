# Titanic Survival Prediction
Titanic survival prediction using Logistic Regression and random Forest | 81% accuracy

# Results
| Model               | Accuracy |
|---------------------|----------|
| Logistic Regression |   81.0%  |
| Random Forest       |   79.3%  |

# What I did
- Loaded and explored real Titanic passenger data (891 rows)
- Cleaned missing values 
- Engineered features and converted categorical data to numbers
- Trained and compared two ML models
- Analysed feature importance

# Key Finding
Fare paid was the strongest predictor of survival (33%), followed by Sex (29%) and Age (25%).

Python, Pandas, NumPy, Scikit-learn
